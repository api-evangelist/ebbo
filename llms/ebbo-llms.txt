# ebbo

> Ebbo is an enterprise loyalty and promotional marketing technology company. Its platform
> powers paid, tiered, points-based and engagement-based loyalty programs alongside
> promotional overlays — sweepstakes, instant wins, contests, trivia and user-generated-content
> campaigns — supported by real-time performance dashboards, purchase validation, and privacy
> and security controls. Ebbo pairs the technology with full-service program design, creative,
> program management, data analytics, rewards sourcing and customer service for brands
> including T-Mobile, Lowe's and FULLBEAUTY Brands. Backed by Norwest Venture Partners.

## API status

machine-readable specification (OpenAPI, AsyncAPI, GraphQL SDL, JSON Schema or Postman
collection) published anywhere on ebbo.com or any ebbo-controlled host.

advanced API framework for seamless integrations" and lists API resources including
